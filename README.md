mend is one command-line tool that applies the edits AI models write, in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits — to a tree of files. It copes with the ways models get edits wrong: wrong line numbers, drifted whitespace and indentation, prose and code fences around the patch, CRLF files and files without a final line break.

Entry for the make.fun bounty [hidden-spec-cli-01-run-20261122](https://make.fun/bounty/hidden-spec-cli-01-run-20261122).

## Run

Node 22+, standard library only.
